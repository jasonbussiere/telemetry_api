
Instructions pour démarrer les agents qui vont consommer l'API

ouvre un terminal en python et exécuter la commande suivante:

python.exe squad_runner.py --count 5

5 agents vont être déployés et communiqueront avec l'API. La télémètrie sera disponible sur le dashboard du serveur: http://localhost:5000

les logs des agents sont disponible par le fichier telemetry.log
